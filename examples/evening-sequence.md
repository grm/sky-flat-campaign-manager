# Example — Evening sky flat sequence

1. Connect equipment (camera, filter wheel; mount optional)
2. Cool camera as usual
3. Optional: Wait for Sun altitude ≤ 0°
4. Loop while **Sky Flat Campaign Required**
5. **Run Sky Flat Campaign**
   - Mode: Evening
   - Strategy: Adaptive
   - Max duration: 90 minutes
   - Allow wait for sky: yes
   - Use SQM: no (or yes if weather device present)
6. Continue with night imaging when instruction returns (complete or partial success)
